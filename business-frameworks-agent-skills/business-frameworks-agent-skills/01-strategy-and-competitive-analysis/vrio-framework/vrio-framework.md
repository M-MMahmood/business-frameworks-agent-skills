# VRIO Framework

## Purpose
Use this skill to test whether resources and capabilities create sustainable competitive advantage.

## When to use
- The user names VRIO Framework explicitly.
- The task matches: test whether resources and capabilities create sustainable competitive advantage.

## Before you start
Confirm or ask for: the company/market/context, the decision being made, the time horizon, and any available data. If data is missing, state assumptions explicitly and label them.

## Process
1. List key resources and capabilities (tangible, intangible, human, organizational).
2. For each, test: Valuable? Rare? Costly to Imitate? Organized to capture value?
3. Classify: competitive disadvantage, parity, temporary advantage, or sustained advantage.
4. Identify which to invest in, protect, or fix.

## Output format
VRIO table with Y/N per test, advantage classification, and recommended actions.
Lead with the answer or key insight first, then supporting detail. Keep the structure MECE and quantify wherever possible.

## Common pitfalls
Calling everything valuable; ignoring organizational support (the O).

## Quality checklist
- [ ] Conclusions are evidence-based and sources or assumptions are stated.
- [ ] Output ends with clear, prioritized recommendations ("so what").
- [ ] Categories do not overlap and nothing material is missing.
