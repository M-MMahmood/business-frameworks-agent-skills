# Value Chain Analysis

## Purpose
Use this skill to find where value and cost are created across activities.

## When to use
- The user names Value Chain Analysis explicitly.
- The task matches: find where value and cost are created across activities.

## Before you start
Confirm or ask for: the company/market/context, the decision being made, the time horizon, and any available data. If data is missing, state assumptions explicitly and label them.

## Process
1. List primary activities (inbound logistics, operations, outbound logistics, marketing and sales, service) and support activities (infrastructure, HR, technology, procurement).
2. Estimate cost and value contribution of each.
3. Benchmark versus competitors.
4. Identify activities to improve, outsource, or redesign.
5. Quantify the margin/advantage impact.

## Output format
Activity table (cost, value, benchmark gap) and prioritized improvement list.
Lead with the answer or key insight first, then supporting detail. Keep the structure MECE and quantify wherever possible.

## Common pitfalls
Ignoring linkages between activities; no quantification.

## Quality checklist
- [ ] Conclusions are evidence-based and sources or assumptions are stated.
- [ ] Output ends with clear, prioritized recommendations ("so what").
- [ ] Categories do not overlap and nothing material is missing.
