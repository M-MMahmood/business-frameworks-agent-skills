# Balanced Scorecard

## Purpose
Use this skill to translate strategy into measures across four perspectives.

## When to use
- The user names Balanced Scorecard explicitly.
- The task matches: translate strategy into measures across four perspectives.

## Before you start
Confirm or ask for: the company/market/context, the decision being made, the time horizon, and any available data. If data is missing, state assumptions explicitly and label them.

## Process
1. Clarify strategic objectives.
2. Define objectives in Financial, Customer, Internal Process, Learning & Growth perspectives.
3. For each, set measures, targets, and initiatives.
4. Draw a strategy map showing cause-effect links.
5. Set review cadence and ownership.

## Output format
Scorecard table (objective, KPI, target, initiative, owner) and strategy map.
Lead with the answer or key insight first, then supporting detail. Keep the structure MECE and quantify wherever possible.

## Common pitfalls
Too many KPIs; lagging metrics only; no causal links.

## Quality checklist
- [ ] Conclusions are evidence-based and sources or assumptions are stated.
- [ ] Output ends with clear, prioritized recommendations ("so what").
- [ ] Categories do not overlap and nothing material is missing.
