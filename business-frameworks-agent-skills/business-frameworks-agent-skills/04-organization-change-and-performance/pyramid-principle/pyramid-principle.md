# Pyramid Principle

## Purpose
Use this skill to structure and communicate recommendations answer-first.

## When to use
- The user names Pyramid Principle explicitly.
- The task matches: structure and communicate recommendations answer-first.

## Before you start
Confirm or ask for: the company/market/context, the decision being made, the time horizon, and any available data. If data is missing, state assumptions explicitly and label them.

## Process
1. Start with the governing answer or recommendation.
2. Group 3 or fewer key supporting arguments (MECE).
3. Support each with data and logic (deductive or inductive).
4. Check vertical logic (each level answers 'why?'/'how do you know?') and horizontal logic.
5. Write the executive summary using Situation-Complication-Question-Answer.

## Output format
Pyramid outline and a one-paragraph executive summary.
Lead with the answer or key insight first, then supporting detail. Keep the structure MECE and quantify wherever possible.

## Common pitfalls
Burying the answer; overlapping arguments; data dumps.

## Quality checklist
- [ ] Conclusions are evidence-based and sources or assumptions are stated.
- [ ] Output ends with clear, prioritized recommendations ("so what").
- [ ] Categories do not overlap and nothing material is missing.
