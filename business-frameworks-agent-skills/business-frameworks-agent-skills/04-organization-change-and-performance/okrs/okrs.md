# OKRs

## Purpose
Use this skill to align goals and measurable results across teams.

## When to use
- The user names OKRs explicitly.
- The task matches: align goals and measurable results across teams.

## Before you start
Confirm or ask for: the company/market/context, the decision being made, the time horizon, and any available data. If data is missing, state assumptions explicitly and label them.

## Process
1. Define 3-5 ambitious, qualitative Objectives for the period.
2. For each, write 2-5 measurable Key Results (outcomes, not tasks).
3. Align and cascade with parent OKRs.
4. Set confidence levels and a check-in cadence.
5. Grade at period end (0-1) and capture learnings.

## Output format
OKR sheet with objective, key results (baseline, target), owner, and confidence.
Lead with the answer or key insight first, then supporting detail. Keep the structure MECE and quantify wherever possible.

## Common pitfalls
Writing tasks as key results; too many OKRs; tying to compensation.

## Quality checklist
- [ ] Conclusions are evidence-based and sources or assumptions are stated.
- [ ] Output ends with clear, prioritized recommendations ("so what").
- [ ] Categories do not overlap and nothing material is missing.
