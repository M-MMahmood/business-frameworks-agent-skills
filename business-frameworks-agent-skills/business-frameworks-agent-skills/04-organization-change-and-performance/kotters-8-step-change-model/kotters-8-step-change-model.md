# Kotter's 8-Step Change Model

## Purpose
Use this skill to lead organizational transformation.

## When to use
- The user names Kotter's 8-Step Change Model explicitly.
- The task matches: lead organizational transformation.

## Before you start
Confirm or ask for: the company/market/context, the decision being made, the time horizon, and any available data. If data is missing, state assumptions explicitly and label them.

## Process
1. Create urgency.
2. Build a guiding coalition.
3. Form a strategic vision and initiatives.
4. Enlist a volunteer army.
5. Remove barriers.
6. Generate short-term wins.
7. Sustain acceleration.
8. Institute change in culture.

## Output format
Step-by-step plan with owners, timing, risks, and metrics for each step.
Lead with the answer or key insight first, then supporting detail. Keep the structure MECE and quantify wherever possible.

## Common pitfalls
Skipping steps; declaring victory too early.

- [ ] Conclusions are evidence-based and sources or assumptions are stated.
- [ ] Output ends with clear, prioritized recommendations ("so what").
- [ ] Categories do not overlap and nothing material is missing.
