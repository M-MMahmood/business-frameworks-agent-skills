# McKinsey 7S Framework

## Purpose
Use this skill to check whether an organization is aligned to deliver its strategy.

## When to use
- The user names McKinsey 7S Framework explicitly.
- The task matches: check whether an organization is aligned to deliver its strategy.

## Before you start
Confirm or ask for: the company/market/context, the decision being made, the time horizon, and any available data. If data is missing, state assumptions explicitly and label them.

## Process
1. Assess hard elements: Strategy, Structure, Systems.
2. Assess soft elements: Shared Values, Skills, Style, Staff.
3. Rate current vs. desired state for each element.
4. Find misalignments, especially with Shared Values at the center.
5. Prioritize interventions and sequence them, noting knock-on effects.

## Output format
7-row table (current, target, gap, action) and an alignment verdict.
Lead with the answer or key insight first, then supporting detail. Keep the structure MECE and quantify wherever possible.

## Common pitfalls
Focusing only on structure and systems; ignoring culture and style.

## Quality checklist
- [ ] Conclusions are evidence-based and sources or assumptions are stated.
- [ ] Output ends with clear, prioritized recommendations ("so what").
- [ ] Categories do not overlap and nothing material is missing.
